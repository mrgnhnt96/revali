# Page brief

- Type and state: open-source developer tool, live at https://revali.dev. Supporting pages: `/privacy/` and a 404.
- Audience: Dart and Flutter developers who want a backend in the language they already use. They know HTTP and Dart. Most don't know Revali.
- The page's one job: show what Revali generates from annotated Dart, then get the visitor running it.
- Primary CTA: "Get started", to the quickstart at `#start` on the same page.
- Secondary action: "Star on GitHub", to https://github.com/mrgnhnt96/revali.
- Search phrases: dart backend framework; dart server framework; dart rest api framework; generate dart api client; flutter backend in dart.
- Objections: is it real code or a demo; how much does it generate and how much do I add; does it run on my stack; what does it cost and who owns it; how much setup does it take.
- Analytics and cookies: PostHog and Amplitude (plain SDK), both from `web/analytics.js`, on every page. Session recording is off in both. Three cookies, listed on `/privacy/`. Off when the visitor turns them off on `/privacy/` or the browser sends Global Privacy Control.
